# Felicity Local Testing Fork

This repository is a personal, experimental testing fork of [Felicity](https://github.com/Hamza417/Felicity), an AGPL-licensed offline music player for Android featuring a custom C++ JNI audio engine, dynamic theming, and an integrated MilkDrop visualizer.

## Modifications and Disclaimer

This fork is configured solely for local experimentation and testing:
* **Feature Access** - Full-version checks inside local trial preference stores are forced enabled.
* **Expiration Handling** - Grace-period and trial expiration hooks are bypassed for evaluation.

*Disclaimer: This build is maintained for personal testing and code review. If you enjoy the original project, please support the upstream developer at [Hamza417/Felicity](https://github.com/Hamza417/Felicity).*
